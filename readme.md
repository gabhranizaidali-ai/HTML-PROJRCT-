# 🚲 Pure Cycles – Bicycle Website Wireframe

## 📌 Project Overview

**Pure Cycles** is a simple bicycle website wireframe created using **HTML5 and CSS3**.

This project demonstrates the basic structure and layout of an online bicycle store. It includes a header, navigation bar, bicycle banner, featured products, promotional section, and footer.

The main purpose of this project is to practice HTML structure, CSS styling, and webpage layout design.

## 🛠️ Technologies Used

- **HTML5** – To create the structure of the webpage.
- **CSS3** – To style the webpage.
- **Flexbox** – To arrange webpage sections vertically.
- **HTML Tables** – To create the wireframe layout.

## 🚀 How to Run the Project

1. Download the project files.
2. Open the project folder in VS Code.
3. Make sure all bicycle images are inside the `asset` folder.
4. Open the `index.html` file in your browser.
5. View the Pure Cycles website wireframe.
